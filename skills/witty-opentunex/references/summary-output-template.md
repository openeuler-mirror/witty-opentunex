# 阶段3完成后总结输出模板【强制】

阶段3调优执行完成后，向用户输出的**总结性内容必须严格遵循以下固定模板**，禁止自由发挥、禁止增删章节、禁止改写表头。

**模板来源**：从阶段3产出的调优报告 `${WORK_DIR}/tuning/tuning-report.md` 中提取关键信息（报告基本信息、瓶颈与调优手段总结表、瓶颈证据/影响分析/调优步骤/回滚方法），按下方结构组织后输出给用户。

**远端模式**：`${WORK_DIR}` 是远端路径，所有读取（`cat`、`grep`）必须经 `opentunex-remote-execution` 的 ssh 在远端执行，禁止 scp 拷回本地。

## 输出硬性约束

1. **章节固定**：3个一级章节（执行概要、核心瓶颈与调优建议、下一步操作）必须全部出现，顺序不可调换
2. **表头固定**：每个表格的表头必须与模板一致，禁止新增/删除/重命名列
3. **内容来源固定**：
   - 「执行概要」表格 → 来自 `${WORK_DIR}/tuning/tuning-report.md` 的「报告基本信息」章节
   - 「2.1 瓶颈与调优手段总览」表格 → 来自 `${WORK_DIR}/tuning/tuning-report.md` 的「1. 总结」章节，每行一一对应，禁止合并/拆分/改写
   - 「2.2 调优建议详情」子节 → 来自 `${WORK_DIR}/tuning/tuning-report.md` 的「2. 调优建议」章节，每个瓶颈一个 `##### 瓶颈N：[描述]` 块，块内 2 个固定子标题（**瓶颈证据** / **影响分析**）必须全部出现且顺序不可调换；调优手段、调优步骤、回滚方法、调优脚本等信息请用户查阅完整报告（不在本节展示）
4. **禁止新增章节**：模板外的内容（如「经验总结」「其他建议」「个人感想」等）一律不允许追加
5. **路径格式固定**：所有路径必须使用完整路径（`${WORK_DIR}/...`），禁止用相对路径或省略
6. **语言一致**：总结输出使用与用户输入相同的语言（中文/英文）
