# 中间态调优建议模板

> **⚠️ 严格限定：生成中间态建议时，必须且只能按照本模板的结构和字段进行填充，禁止添加模板中不存在的任何内容。**
>
> **禁止添加的内容包括但不限于**：
> - "已生效调优"、"已验证"等执行状态描述
> - "系统基线"、"最优"等评估性标签
> - "产出数据索引"等非模板定义的章节
> - 冲突分析、执行计划、风险提示与回滚方案等章节
> - 任何模板未定义的表格、列表或章节
>
> **正确做法**：严格按照模板结构，将分析得到的数据填入对应字段，不多不少。

---

## 模板正文

```markdown
# [调优方向] 调优建议

## 1. 瓶颈点列表

| 瓶颈点 | 类别 | 严重程度 | 影响描述 | 调优手段 | 调优步骤 | 调优脚本 |
|--------|------|----------|----------|----------|----------|----------|
| [瓶颈描述] | [CPU/内存/磁盘/网络/应用/调度] | [严重/高/中/低] | [对系统性能的影响] | [简短调优方向] | [精简操作步骤，如：1.xxx 2.xxx] | [脚本路径，如：./xxx/tuning.sh] |

## 2. 调优建议详情

### [瓶颈点描述]

**瓶颈证据**：
- [证据1：具体指标数据]
- [证据2：具体指标数据]

**影响分析**：
- [对系统性能的具体影响分析]

**调优手段**：
- [简短调优方向描述]

**调优步骤**：
```bash
# [操作描述]
[调优命令1]
# [操作描述]
[调优命令2]
```

**回滚方法**：
```bash
# [回滚操作描述]
[回滚命令1]
# [回滚操作描述]
[回滚命令2]
```

**调优脚本**：`./[脚本路径]/tuning.sh apply`

**验证方法**：
```bash
# [验证操作描述]
[验证命令]
```
```
