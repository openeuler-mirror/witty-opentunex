# 瓶颈分析域强制约束

## B-01: 重新执行
每次触发都必须重新从头执行完整分析流程，不得引用历史数据或之前的回答。

## B-02: 数据目录约定
- 写入路径：${WORK_DIR}/analysis/[skill_name]_collect/
- 读取路径：${DATA_DIR}/ 或 ${WORK_DIR}/（预采集模式）；${WORK_DIR}/（按需采集模式）
- 禁止直接写入 ${WORK_DIR}/analysis/ 根目录
- 所有路径中的 ${WORK_DIR}/ 均指用户指定的工作目录，可通过 OPENTUNEX_WORK_DIR 环境变量自定义
- ${DATA_DIR} 为用户指定的预采集数据目录，优先级高于 ${WORK_DIR}/
- 远端场景（目标为远端服务器）时，`${WORK_DIR}` 为远端路径：上述读写均须经 `opentunex-remote-execution` 的 ssh 机制在远端执行（读直接在远端机器读取——远端 cat/grep 流回上下文，禁止拷贝到本地后读取；写**直接在远端机器产出**——经 ssh 在远端落盘，禁止本地生成后 scp 上传），禁止在 agent 本地操作 `${WORK_DIR}`。详见 `opentunex-remote-execution/references/work_dir_remote_semantics.md`

## B-03: 数据采集约束
协调器和子技能**禁止自行采集数据**，必须基于数据目录中已采集的数据进行分析。

数据采集由前置环节负责，协调器和子技能无需关系如何采集数据。

## B-04: 数据缺失处理
数据缺失时：
1. 子技能在结果中标注 `DATA_MISSING: <缺失文件列表>`
2. 关键数据全部缺失时，子技能输出"数据不足"结论

## B-05: 通用分析与场景化分析必须并行
两者视角互补，不可串行替代。输出契约中必须包含并行启动的时间戳证据。

## B-06: 场景化分析全量调度
不做选择性过滤，由各场景自行判断适用性。

## B-07: 结果融合必选
两类分析结果必须经过融合，确保调优层收到一致、无冲突的结论。

## B-08: 子技能严格串行调用（唯一执行方式）

场景化分析域对所有场景分析子技能采用**唯一**的执行模式——**严格串行调用**，不存在子智能体并发调度分支，也不存在"降级"路径选择。

### 串行调用规则

1. **一次只加载一个子技能**：当前轮只加载一个子技能 SKILL.md 并执行其完整流程，**禁止**一次性加载多个子技能 SKILL.md 后批量调度
2. **完成后再加载下一个**：当前子技能的全部产出（输入/输出契约 + 分析报告）写入磁盘后，才能开始加载下一个子技能 SKILL.md
3. **禁止子智能体并发调度**：禁止通过任何子智能体工具（Task Tool / Agent Tool / sessions_spawn 等）**同时**启动多个子技能；本约束**不禁止**子技能内部为执行其自身步骤而单独使用子智能体能力，但子技能之间必须串行
4. **禁止内联执行**：禁止在协调器上下文中读取子技能 SKILL.md 后直接执行其分析逻辑
5. **禁止协调器读取采集数据**：协调器不得读取任何采集数据文件内容（仅允许存在性检查）；数据文件的读取只能发生在子技能执行流程内
6. **全量调度**：所有场景分析子技能均需调用，不做选择性过滤

### 与 B-05 的关系

- B-05「通用分析与场景化分析必须并行」是**顶层编排层**的并行约束（通用分析技能与 opentunex-scenario-bottleneck 之间），不属于本约束管辖范围
- 本 B-08 管辖范围仅限 opentunex-scenario-bottleneck 内部子技能之间的调用方式，**不影响 B-05 的并行要求**

### 禁止性条款

- 不得以"更高效/更方便"等主观判断绕过串行约束，采用并发或批量加载
- 不得以"子智能体工具可用"为由自动切换到并发调度模式
- 不得在协调器当前上下文中内联执行任何子技能的分析步骤
- "数据已加载到上下文"不是跳过子技能独立执行的正当理由；子技能应独立加载自己的上下文，路径而非内容写入输入契约

## 确认方式
协调器在融合输出契约的 `constraints_acknowledged` 字段中列出已遵守的约束编号，并在 `constraints_version` 字段中填写本约束文件版本号。
示例：constraints_acknowledged: ["B-01: 重新执行", "B-02: 数据目录约定", "B-03: 禁止自行采集", "B-04: 数据缺失处理", "B-05: 通用分析与场景化分析必须并行", "B-06: 场景化分析全量调度", "B-07: 结果融合必选", "B-08: 子技能严格串行调用"]
