# 数据采集强制约束

constraints_version: "v2.0"

## C-01: 只读操作
所有数据采集均为只读，不修改系统状态。

## C-02: 禁止内联命令
必须直接调用采集脚本，禁止内联执行脚本中的命令。

## C-03: 原始数据保留
采集过程中保留原始数据，不做过滤、清洗或分析。脚本输出直接落盘到报告文件。

## C-04: 数据目录约定
- 轻量编排/单项采集：报告写入 `${BATCH_DIR}/<item>-collection_report.txt`
- 一键采集：报告写入 `-o` 指定目录（默认 `profiling_data_<arch>_<时间戳>/`）
- 所有路径中的 `${WORK_DIR}/` 均指工作目录，可通过 `OPENTUNEX_WORK_DIR` 环境变量自定义

## C-05: 脚本直接落盘
采集脚本将数据直接写入报告文件，skill 不读取或改写采集内容，仅负责调度与结果汇总。

## C-06: 降级处理
工具不可用时脚本自动降级，标注不可用项，不中断整体流程。
